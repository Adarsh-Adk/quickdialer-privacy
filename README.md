# Quick Dialer privacy policy

Privacy policy for the Quick Dialer Android app (`in.appsbyadarsh.quickdialer`), served with
GitHub Pages.

- Page: `index.html`
- Public URL (once Pages is on): `https://adarsh-adk.github.io/quickdialer-privacy/`

When the app's permissions, libraries or data handling change, update `index.html`, change the
"Effective" date, and keep the Play Console Data safety form in sync.
